# Voodoo 스타일 1인칭 레이캐스팅 RPG — 프로토타입

Path of Kings 처럼 자동으로 앞으로 나아가는 1인칭 던전 러너. 화면은 Wolfenstein 풍 레이캐스팅으로 실시간 렌더링되고, 플레이어는 갈림길/이벤트에서 선택만 하며, 전투는 장비 빌드에 따라 자동으로 처리된다.

## 화면 구성 (모바일 세로 우선, / 경로)

```text
+------------------------------+
|  HP ███████   Lv.3   Gold 120|
+------------------------------+
|                              |
|     레이캐스팅 3D 뷰          |
|   (벽/문/적 스프라이트)        |
|                              |
|      [무기 스프라이트]         |
+------------------------------+
|  이벤트 카드 / 선택지 2~3개    |
+------------------------------+
|  장비 슬롯: 무기 방어구 부적    |
+------------------------------+
```

## 핵심 루프

1. 캐릭터가 복도를 자동으로 전진 (일정 속도, 카메라 bob 효과)
2. 분기점/문 앞에 도달하면 정지 → 선택 카드 표시
   - 왼쪽 길 / 오른쪽 길
   - 보물상자: 장비 획득 or 함정
   - 상인: 골드로 장비 교체
3. 적을 만나면 자동 전투 시작 → 전진 정지, 결과 로그 표시
4. 승리 시 골드/장비 획득 후 전진 재개, 패배 시 게임오버 → 재시작

## 자동 전투

- 스탯: 공격력, 방어력, 체력, 공격속도, 치명타
- 장비 3슬롯(무기/방어구/부적)이 스탯에 합산되어 승패를 좌우
- 일정 간격 틱으로 서로 피해 교환, 화면에 데미지 숫자 팝업 + 적 스프라이트 흔들림
- 플레이어 개입은 없음(관전형). 전투 전 선택 단계에서만 빌드를 바꿈

## 프로토타입 범위

- 던전 1개(절차 생성 복도 맵, 약 10개 노드 길이)
- 적 3종: 고블린 / 스켈레톤 / 오크(보스)
- 장비 9종(슬롯당 3티어)
- HP·골드·레벨 HUD, 게임오버/클리어 화면, 재시작
- 저장 기능 없음(세션 단위)

## 아트

- 벽/바닥/천장: 절차 텍스처 + 거리 기반 명암(어두운 지하 던전 톤)
- 적과 무기: AI 생성 투명 PNG 스프라이트를 빌보드로 렌더
- 색: 횃불빛 앰버 + 깊은 돌회색, 픽셀 느낌 폰트

## 기술 메모

- `src/routes/index.tsx` 를 게임 화면으로 교체(플레이스홀더 제거)
- 렌더러: `<canvas>` + DDA 레이캐스터, `requestAnimationFrame` 루프, 클라이언트 전용(`useEffect` 안에서 초기화)
- 게임 상태: `src/game/` 하위에 맵 생성기 / 전투 시뮬레이터 / 장비 테이블 순수 모듈, React 는 HUD·선택 카드만 담당
- 백엔드 없음(로컬 상태만), 디자인 토큰은 `src/styles.css` 에 던전 팔레트로 추가
